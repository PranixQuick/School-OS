# Where test evidence lives

Every CI run uploads a dated evidence bundle as a GitHub Actions artifact.
Nothing in this repository should claim a test passed without linking to one of
those bundles.

| Artifact | Contents |
|---|---|
| `playwright-report` | Full HTML report: per-test pass/fail, traces, videos, screenshots |
| `test-results` | JUnit XML (`e2e-junit.xml`, `unit-junit.xml`), raw traces, `EVIDENCE_RUN.md` |
| `coverage` | V8 line/branch coverage for the unit suite |

`EVIDENCE_RUN.md` is generated by the workflow and records the commit SHA, the
run URL, the date and the pass/fail counts for each suite. Paste its contents
into `EVIDENCE_LEDGER.md` when closing out a test-matrix item, and link the run.

## Why this exists

Before Phase 0 the repository contained three documents asserting that tests had
passed, and no artifact anywhere proving that any test had ever run on any given
date. `test-results/.last-run.json` held 45 bytes with no date and no test list.
The evidence ledger was an empty template.

A claim without a run URL is not evidence.
